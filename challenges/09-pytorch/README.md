# Challenge 9 - PyTorch

**Topic:** Deep learning frameworks &nbsp;|&nbsp; **Techniques:** PyTorch, data preparation, architecture selection, hyperparameter exploration &nbsp;|&nbsp;
**Data:** student-selected: tabular, text, image or audio

## Description

We have finally reached the last part of the course and thus we introduced production-ready deep
learning libraries that you can use for your projects.

In Notebook 7 (PyTorch) you can find a few complete examples about how to use the library with the toy
datasets that we adopted during the whole course. You can use this notebook as a starting point for
understanding how the library should be used - in addition to reading the library documentation.

## Your task

You are challenged to address a real-world problem using the PyTorch library to solve it. It can be
either a regression or a classification problem. Specifically you have to:

1. **Select a dataset.** This dataset can include feature-based data points, text, images, audio -
   whatever you think could be interesting.
2. **Prepare the data.** Write the code needed to prepare the data so it can be used to train a
   network. Also find out which output you want to predict, or which classes you want to detect.
3. **Choose a network architecture.** Choose the most suitable type of network, its layers, the loss
   function and all the characteristics that you think are suitable to solve the problem.
4. **Train and test.** Train and test your network. Try changing a few hyperparameters and/or some
   details of the network architecture to find out which works best. Present the results inside the
   notebook using meaningful plots.

> **Course materials.** This statement refers to lecture notebooks that are distributed separately and
> are not part of this repository. If you are working the challenge independently, treat the reference
> as background and implement the pieces yourself.
