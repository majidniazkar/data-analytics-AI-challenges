# Challenge 8 - Fine tuning

**Topic:** Deep learning from scratch &nbsp;|&nbsp; **Techniques:** Softmax cross-entropy, learning-rate decay, momentum, Glorot initialization, dropout &nbsp;|&nbsp;
**Data:** student-selected: at least 10 features, 2-3+ classes

## Description

We have finally completed all the code parts for a full-fledged deep neural network. Specifically,
during the last lecture we introduced the ability of using the network as a classifier, using the
softmax cross-entropy loss, and we defined a few different learning-rate decay modes, the momentum,
the Glorot weights initialization and the dropout operation.

In Notebook 4 (Extensions) you can find all the code needed and a complete example section where
different network architectures and a few of the aforementioned fine-tuning techniques are shown with
a real-world classification task. You can use this notebook as a starting point for your assignment by
reusing all the code already available.

## Your task

You are challenged to design a few network architectures, by changing the topology and testing a few
fine-tuning techniques, and execute a batch of tests to determine which works best with your data.
Specifically you have to:

1. **Select a new dataset.** Find a new dataset that contains at least 10 distinct features. The
   dataset should be usable to define a classification task with at least two or three classes, so
   some feature must be qualitative and usable as the variable to predict.
2. **Design a few different networks.** Change the topology and adopt a few of the studied fine-tuning
   techniques.
3. **Compare the networks.** Test them with the same dataset and finally choose the best one.
