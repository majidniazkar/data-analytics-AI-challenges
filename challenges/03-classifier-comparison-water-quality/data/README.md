# Water quality dataset

`water_quality_295.csv` - shared by challenges 3, 4 and 5.

295 samples adopted from an online repository (https://www.kaggle.com/datasets/lakhanlalgupta/dataforwqi?resource=download&select=Results_MADE.csv): nine input parameters and a Water Quality Index (WQI)
target.

| Column | Unit |
|--------|------|
| Temperature | degrees C |
| Dissolved Oxygen | mg/L |
| pH | - |
| Bio-Chemical Oxygen Demand | mg/L |
| Faecal Streptococci | MPN/100 mL |
| Nitrate | mg/L |
| Faecal Coliform | MPN/100 mL |
| Total Coliform | MPN/100 mL |
| Conductivity | mho/cm |
| WQI | - |
